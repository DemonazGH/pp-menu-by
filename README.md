# ПростоПП

Персональный планировщик правильного питания на неделю:

- меню на 1450–1500 ккал в день;
- рецепты с граммовками и пищевой ценностью;
- две основные готовки в неделю;
- замена блюд на равноценные;
- интерактивный список покупок.

Сайт публикуется автоматически через GitHub Pages после изменений в ветке `main`.
